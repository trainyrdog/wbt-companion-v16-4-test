# WBT Companion App v16.7 — Polished PWA Test Candidate

Use this ZIP for the next test. This build is focused on public wording, compact first screens, safer navigation, and stable local-device testing.

## Test steps

1. Open the app. The Home screen should feel compact, not like a long development roadmap.
2. Tap Dog Profile and enter a dog name. No black screen should appear.
3. Save the profile, close/reopen the browser/app, and confirm it stays saved on the same device/browser.
4. Run one Behaviour Assessment and generate a report.
5. Start a 7-day observation and confirm it appears in the Log.
6. Open Learn, Help, and WBT Guide. They should use public-facing wording only.
7. Open WBT links and confirm they open outside the app.

No live AI, no login, no payment, no backend, no database, and no community layer are connected in this build.
